# 開發日誌：Phase 10.1 修正 GitHub CI 前端測試失敗

## 1. 任務概述
- **目標**：解決 GitHub Action 中的 「Frontend Build Check」失敗問題。
- **現象**：`npm test` 執行失敗，具體源於 `__tests__/app/page.test.tsx` 的 Sidebar 渲染斷言錯誤。

## 2. 核心分析 (First Principles)
- **UI 渲染邏輯變更**：`Sidebar.tsx` 將選單標籤（如 `標題 (subtitle)`）拆分為兩個 `span` 渲染，導致 `screen.getByText` 無法匹配完整字串。
- **選單內容更新**：側邊欄選單名稱與路徑已更新（如「總覽」變更為「首頁面板」），但測試案例未同步。
- **Mock 環境不完全**：`page.tsx` 間接引用了 `useAlerts` hook，其內部使用了 Supabase Realtime 訂閱（`channel`, `on`, `subscribe`），原本的 Mock 缺失這些方法導致 `TypeError`。

## 3. 解決方案 (KISS 原則)
- **組件更新**：在 `Sidebar.tsx` 的 Logo 圖示添加 `data-testid="icon-cpu"` 以滿足測試定位需求。
- **測試同步**：
    - 更新 `page.test.tsx` 斷言，僅搜尋拆分後的中文字標記（如 `首頁面板`、`籌碼分析`）。
    - 補足 Supabase Mock 對象中的鏈式呼叫方法（`channel`, `on`, `subscribe`, `removeChannel`）。
- **驗證**：本地執行 `npm test` 確保 0 錯誤、0 警告。
