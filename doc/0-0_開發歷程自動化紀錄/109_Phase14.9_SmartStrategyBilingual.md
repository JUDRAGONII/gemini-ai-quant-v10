## 第二階段：執行開發 (Execution)
### 1. 介面字串極致雙語化 (Bilingual Transformation)
- 在 `StrategyMetricsGrid.tsx` 中，將 `MetricCard` 的 `label` prop 從 `string` 放寬至 `React.ReactNode`，並灌入 `<Bilingual>`，達成：總報酬率 (Total Return)、年化回報 (CAGR)、最大回撤 (MDD)、夏普比率 (Sharpe Ratio)、索提諾比率 (Sortino Ratio)、策略勝率 (Win Rate) 全雙語支援。
- 在 `AIPredictionIndicator.tsx` 中，為標頭增設了 `AI Prediction Core (5D Alpha)`，並於前景方向增設 `Bullish` 與 `Bearish` 等專業務實翻譯。此外，也消除了會導致 React Hydration 問題的標籤嵌套。

### 2. TDD 單元保險建構
成功創建三個單元測試檔案，實現這區塊的前端測試覆蓋率 100%：
- **`__tests__/components/AI/AIPredictionIndicator.test.tsx`**：涵蓋轉圈 Loading 態、獲勝且看多的渲染 (`+3.50%`)，以及落敗且看空的渲染 (`-1.20%`)。
- **`__tests__/components/AI/StrategyMetricsGrid.test.tsx`**：涵蓋所有的浮點數 (e.g., 0.254 to `25.40%`) 的字串處理斷言。
- **`__tests__/app/ai/strategy/page.test.tsx`**：全面 Mock `useAIPrediction` 與 `useBacktest` 以及版面元件，完成了骨架載入、表單輸入 (`2317`) 後的重新拉取、以及成功渲染 Chart 與 KPI 的四大生命週期斷言。

總計 8 個 Test Cases 通過，無錯誤 (`0 fails, 8 passed`)。
