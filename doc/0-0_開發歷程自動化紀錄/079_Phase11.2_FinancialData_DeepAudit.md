# 079_Phase11.2_FinancialData_DeepAudit (金融數據深度盤點與計畫重構)

## 1. 需求背景 (Background)
在 Phase 11.2 結項後，發現資料庫呈現「初始空庫」狀態，導致前端數據監控中心顯示異常。需根據 V10.0 憲級文檔重新定義數據範疇並制定回補計畫。

## 2. 深度盤點結果 (Audit Findings)
*   **物理取證**: 除 `schema_migrations` 外，其餘 64 張表筆數均為 0。
*   **數據斷層**: 
    - `exchange_rates` 表缺失（確係 Phase 11 重構時遺失）。
    - 500 萬筆歷史行情資料由於回滾操作未同步恢復。
*   **規約校準**: 依照 V10 PCM 指令，補齊目標標的如下：
    - 台股市場: 全市場標的 (init_stock_list.py)。
    - 美股市場: 核心 660+ 指數成分股。
    - 宏觀: FRED 130+ 指標。
    - 匯率: USD/TWD, USD/CNY, DXY。

## 3. 解決方案：V2 回補計畫 (Solution: Backfill Plan V2)
*   **策略**: 分層回補 (Tiered Backfill)。
*   **基準**: 優先補齊 2330, 0050, SPY, NVDA 等核心 benchmark。
*   **自動化**: 整合 Tiingo Key 輪詢與 429 物理降維冷卻 (3s delay)。
