# 開發日誌：059_Phase8.5_StrategyHub_UI_Optimization

## 📝 任務描述
優化智慧策略看板 (Strategy Hub) 的 UI/UX，解決使用者回報的導航缺失、功能理解困難以及圖表交互失效等問題。

- **日期**: 2026-02-02
- **階段**: Phase 8.5 (UI/UX 拋光)
- **狀態**: 已完成 (COMPLETED)

## 🔍 需求解構
1. **導航強化**: 頁面頂部缺乏返回機制，用戶在深層 AI 分頁中容易迷失。需加入返回鍵。
2. **預測閾值說明**: 「預測閾值」為量化核心概念，對非專業用戶較為晦澀，需加上直觀的文字定義。
3. **圖表交互**: 績效走勢圖的 1W/1M/3M/6M 切換按鈕雖然存在，但後端數據未進行時間過濾，導致數據點過多且無反應。

## 🛠️ 執行開發 (Implementation)

### 1. 導航系統 (Navigation)
- **工具**: `next/navigation` -> `useRouter`
- **實作**: 
  - 在頁面標題上方新增一個 Glassmorphism 風格的返回按鈕，點擊執行 `router.back()`。
  - 同時加入 Breadcrumb (HOME / STRATEGY HUB)，提升層次感。

### 2. 說明文字 (Onboarding)
- **實作**:
  - 在預測閾值輸入框下方加入一行灰色提示字元：`漲幅預測 > { (threshold * 100).toFixed(1) }% 時執行買入`。
  - 統一標籤顏色為 `text-gray-400`，提升設計質感。

### 3. 圖表數據過濾 (Data Slicing)
- **實作**:
  - 新增 `period` 狀態，預設為 `1Y`。
  - 移除原先寫死的 `1Y` 傳參。
  - 核心邏輯：使用 `useMemo` 根據當前 `period` 對 `data.charts.equity` 進行 `Date` 比較與過濾。
  - 成功解決點擊週期按鈕圖表不更新的問題。

## ✅ 驗證結果
- **UI 表現**: 中文字元顯示正常，佈局在 RWD (中/大螢幕) 下保持穩定。
- **功能驗證**:
  - [x] 返回鍵點擊可正常退回前一頁。
  - [x] 預測閾值數值變動時，下方的提示文字同步更新。
  - [x] 圖表週期切換 (如切換至 1W) 時，X 軸標籤與曲線點數正確縮減。

## 💡 經驗教訓
- 在深層分頁中，導航的回退路徑 (Affordance) 與標籤說明的清晰度與核心算法同樣重要。
- 前端數據處理 (Slicing) 在面對海量日 K 數據時，應優先在 `useMemo` 中過濾以保證渲染效能。
