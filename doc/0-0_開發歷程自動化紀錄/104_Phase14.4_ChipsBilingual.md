### 4. 錯誤防範紀錄 (Lessons Learned)
- **問題**：測試時出現 `__tests__/components/layout/MobileNav.test.tsx` 物件索引報錯 (`Element implicitly has an 'any' type`)。
- **原因**：TypeScript 中 `Proxy` 的 `iconCache` 若未聲明 `Record<string, any>`，用字串索引會報錯。
- **對策**：補上型別宣告 `const iconCache: Record<string, any> = {};` 和 `prop as string` 以度過嚴格檢查。
