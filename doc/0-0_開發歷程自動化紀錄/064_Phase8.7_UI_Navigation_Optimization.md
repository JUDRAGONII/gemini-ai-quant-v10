# Dev Log 064: 個股佈局優化、AI 報告標籤化與導航修復

## 📅 日期: 2026-02-02
## 👤 執行者: Antigravity

---

### 🔍 問題診斷 (Root Cause Analysis)
1. **佈局冗餘**: 個股詳情頁面同時存在兩個「返回」按鈕（Layout 頂部與 Page 內部），造成視覺混亂。
2. **決策報告分散**: AI 報告目前處於獨立路徑（/ai/[id]），使用者希望在個股詳情中以「活頁標籤」形式與財務、技術分析整合。
3. **導航路徑偏離**: 原本的「查看 AI 投資報告」按鈕導向了搜尋中心 (`/ai/search`)，而非具體的標的報告頁。

### 🛠️ 執行動作 (Actions Taken)
1. **佈局重構 (UI/UX Pro Max)**:
    - 修改 `StockDetailLayout`：將返回按鈕統一移至頂層 Header 位置，改用圓角按鈕風格並移除原文字連結。
    - 清理 `StockDetailPage`：移除頁面內部的重複返回按鈕，保持介面簡約。
2. **AI 報告標籤化**:
    - 在個股詳情導航欄中新增「AI 決策報告」活頁。
    - 建立新路由 `app/stocks/[symbol]/report/page.tsx`，專門渲染該標的的最新一份 AI 分析。
3. **導航邏輯優化**:
    - 修改所有「查看 AI 投資報告」入口（排行榜、個股總覽），一律精確導航至 `/stocks/[symbol]/report`。
    - 更新 `api/ai/reports` API：支援按 `symbol` 獲取 `latest` 完整報告數據。
4. **系統安全性增強**:
    - 在 `docker-compose.yml` 中傳遞 `SERVICE_ROLE_KEY` 給前端，確保伺服器端請求能正確調取資料庫進行報告渲染。
