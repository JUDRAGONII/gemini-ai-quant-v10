# 082_Phase11.2_Deep_History_Audit (全歷史極限調研)

## 1. 需求背景 (Background)
用戶要求數據回補範圍應達到「全歷史 (Full History)」，包含台股 1990 年以前的數據。然而 TWSE 官方 JSON 數據僅提供至 2004-02-11 左右，需尋找第三方遺產源補足斷層。

## 2. 調研結論 (Research Findings)
- **台股大盤指數 (`^TWII`)**: Yahoo Finance 資料可探測至 **1990 年以前** (基期為 1966)。
- **台股個股 (如 2330)**: Yahoo Finance 最早紀錄約為 **1994 年**。
- **官方 JSON 極限**: 2004-02-11 為 TWSE 網頁端提供結構化數據的 hard break point。
- **FRED (宏觀)**: 具備極強歷史深度，部分核心指標可追溯至 **1950s**。

## 3. 解決方案：雙極限雙軌制 (Dual-Limit Hybrid Mode)
採用分段擷取邏輯，最大限度壓榨免費 API 的歷史價值：

| 數據類型 | 1990 以前 ~ 2004-02-10 | 2004-02-11 ~ 至今 |
| :--- | :--- | :--- |
| **台股行情** | **Yahoo Finance (Legacy Source)** | **TWSE Official (Authority Source)** |
| **美股行情** | **Tiingo (1990+)** | **Tiingo (Active)** |
| **宏觀數據** | **FRED (Max Depth)** | **FRED (Active)** |

## 4. 實作要點
- 實作 `HybridMarketFetcher` 負責分界點判定與 API 切換。
- 針對 1990 以前的數據加入「極限偵測 (Max Depth Probe)」機制，即由當前日期往回遞減至 API 報回 404/空值為止。
