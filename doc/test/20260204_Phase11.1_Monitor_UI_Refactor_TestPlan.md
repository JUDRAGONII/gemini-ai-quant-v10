# 20260204_Phase11.1_Monitor_UI_Refactor_TestPlan.md

## 測試目標
驗證**數據監控中心 UI 改造**的核心邏輯，包含：
- 9 分類卡片正確渲染
- CATEGORIES 配置結構運作
- 色彩主題映射
- 待補充狀態 (匯率/貴金屬) 交互禁用
- RPC `get_category_counts` 正確返回數據

## 測試環境
- **Framework**: Next.js 14, Jest, React Testing Library
- **Target Files**:
  - `frontend/app/admin/monitor/page.tsx`
  - `backend/db/migrations/20260204_category_counts_rpc.sql`
- **Test Files**: `frontend/__tests__/admin/monitor/page.test.tsx`

## 測試案例清單

### 1. 基礎路徑測試 (Happy Path)

#### MonitorPage 組件渲染
- [x] **TC-1101: 頁面載入後應渲染 9 個分類卡片**: 驗證 CATEGORIES 配置正確映射為 9 個卡片元素
- [x] **TC-1102: 各卡片應顯示正確分類名稱與英文代碼**: 台灣行情 (TWSE)、美國行情 (US Equities) 等
- [x] **TC-1103: 預設選中第一個分類 (台灣行情)**: activeTab 應為 `tw_equity`

#### 統計數據取得
- [x] **TC-1201: 調用 get_category_counts RPC 應返回 JSON 物件**: 包含 tw_equity, us_equity, tw_macro, us_macro 等 key
- [x] **TC-1202: 卡片應顯示對應分類的記錄數**: stats[category.id] 正確渲染

#### 卡片切換互動
- [x] **TC-1301: 點擊卡片應切換 activeTab 與 activeCategory**: setActiveTab 與 setActiveCategory 被正確調用

### 2. 邊界條件測試 (Edge Cases)
