# 20260128_15_Margin_Validation (融資融券頁面驗收)

## 1. 測試目標
- 驗證融資融券頁面正確顯示融資餘額趨勢。
- 驗證融券餘額趨勢圖顯示。
- 驗證融資使用率顯示。
- 驗證週期切換功能（30/60/90 天）。
- 驗證 API 端點功能。

## 2. 測試環境
- **OS**: Windows (Localhost)
- **Frontend**: Next.js 14, Recharts
- **Backend**: Supabase PostgreSQL
- **Test Date**: 2026-01-28
- **Browser**: Chrome 120+
