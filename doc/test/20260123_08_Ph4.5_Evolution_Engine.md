# 20260123_08_Ph4.5_Evolution_Engine.md

## 測試目標
驗證 AI 演化運算引擎 (Evolution Engine) 的核心邏輯，確保遺傳演算法 (GA) 能正確優化投資組合權重，並透過回測系統計算適應度 (Fitness)。

## 測試環境
*   **Framework**: Python 3.10+, Pytest
*   **Libraries**: DEAP, Pandas, Numpy
*   **Target Files**: 
    - `backend/agents/evolution.py` (演化引擎)
    - `backend/agents/backtest.py` (回測評分)
*   **Test Files**: `backend/tests/test_evolution.py`

## 測試案例清單

### 1. 基礎路徑測試 (Happy Path)
#### [Evolution Engine Setup]
- [x] **TC-1101: DEAP 環境初始化**: 驗證 FitnessMax 與 Individual 類別是否正確註冊，基因長度應為 26 (對應 26 項因子)。
- [x] **TC-1102: 種群初始化 (Population)**: 驗證 `init_population(n=50)` 能產生包含 50 個個體的列表，且每個個體基因數值介於 0~1 之間。

#### [Backtest Logic]
- [x] **TC-1201: 夏普比率計算 (Sharpe Ratio)**: 輸入已知序列，驗證 `calculate_sharpe(returns)` 輸出結果精確度 (Tolerance < 1e-6)。
- [x] **TC-1202: 適應度評估 (Evaluation)**: 輸入一組基因權重與歷史數據，驗證回測函數能返回合法的 (Sharpe, Drawdown) Tuple。

### 2. 演化操作測試 (Evolution Operators)
- [x] **TC-2101: 交叉操作 (Crossover)**: 驗證 `mate()` 函數操作後，子代基因來自於兩個親代，且長度保持不變。
- [x] **TC-2102: 突變操作 (Mutation)**: 驗證 `mutate()` 函數能隨機改變基因數值 (變異率需在預期範圍內)。
- [x] **TC-2103: 選擇機制 (Selection)**: 驗證 `select()` (如 Tournament Selection) 能傾向保留高適應度個體。

### 3. 邊界條件與安全性
- [x] **TC-3101: 權重正規化邊界**: 驗證基因權重總和為 0 或負值時的正規化處理，防止 DivisionByZero。
- [x] **TC-3102: 數據不足防護**: 當回測數據少於最低窗口 (如 30 天) 時，應返回預設懲罰分數 (Fitness = -Infinity)。

### 4. 整合測試 (Integration)
- [x] **TC-4101: 完整演化週期**: 執行一代完整流程 (Evaluate -> Select -> Mate -> Mutate)，驗證族群規模不變且最大適應度非遞減。
- [x] **TC-4102: 資料庫寫入**: 驗證最佳個體 (HallOfFame) 能正確序列化並寫入 `evolution_genes` 資料表。
