# 20260202_Phase8.7_StockDetail_Optimization_TestPlan.md

## 測試目標
驗證 Phase 8.7 的個股詳情佈局優化、AI 決策報告標籤功能、API 連線修復以及跨組件數據一致性。

## 測試環境
*   **Framework**: Next.js 14, Jest, React Testing Library
*   **Target Files**: 
    - `frontend/app/stocks/[symbol]/layout.tsx`
    - `frontend/app/stocks/[symbol]/page.tsx`
    - `frontend/app/stocks/[symbol]/report/page.tsx`
    - `frontend/app/api/ai/reports/route.ts`
*   **Test Files**: `frontend/__tests__/**`

## 測試案例清單

### 1. 基礎路徑測試 (Happy Path)

#### 個股詳情導航 (Navigation)
- [x] **TC-1101: 頂部返回按鈕渲染**: 驗證 Layout 頂部出現「返回行情中心」按鈕，且點擊後正確導向至 `/stocks`。
- [x] **TC-1102: AI 決策報告標籤存在性**: 驗證導航欄出現「AI 決策報告」活頁標籤。
- [x] **TC-1103: 報告分頁內容加載**: 點擊「AI 決策報告」後，頁面應正確渲染 Gemini 報告全文與雷達圖。

#### 智慧排名整合 (Ranking Integration)
- [x] **TC-1201: 查看報告按鈕跳轉**: 在排行榜點擊「查看 AI 投資報告」，應精確跳轉至 `/stocks/[symbol]/report`。

### 2. 邊界條件測試 (Edge Cases)

#### API 容錯 (API Resilience)
- [x] **TC-2101: 報告數據缺失處理**: 當標的無 AI 報告時，`/stocks/[symbol]/report` 應顯示「暫無 AI 決策報告」的友善提示卡片。
- [x] **TC-2201: 異常代號輸入**: 輸入不存在的個股代號時，個股詳情頁應顯示「無法載入數據」提示。

### 3. 安全性與數據一致性

#### 評分同步驗證 (Score Consistency)
- [x] **TC-3101: 加權總分同步**: 驗證雷達圖中間顯示的總分與排行榜（加權評分）完全一致，消除算法歧義。

#### 服務端連線安全 (Internal Networking)
- [x] **TC-3201: Docker 內部 API 連線**: 驗證伺服器端請求 API 時使用的是 `INTERNAL_SUPABASE_URL`，確保跨容器通訊不報 404。

### 4. 可訪問性與 UI/UX

#### 清爽佈局驗證 (Clean UI)
- [x] **TC-4001: 冗餘按鈕移除**: 確認個股總覽頁面中不再出現重複的「返回」按鈕。
- [x] **TC-4002: 圖示渲染正確性**: 驗證 `FileText` (報告圖示) 在導航標籤中正常顯示，無編譯錯誤。
