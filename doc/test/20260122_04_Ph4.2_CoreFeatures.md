# 20260122_04_Ph4.2_CoreFeatures_TestPlan.md

## 測試目標
驗證 Phase 4.2 核心功能強化，包含股票查詢模組、個股詳情頁、以及 AI 評分排行系統的顯示與互動邏輯。

## 測試環境
*   **Framework**: Next.js 14, Jest, React Testing Library
*   **Target Files**: 
    - `app/stocks/page.tsx`, `app/stocks/[symbol]/page.tsx`
    - `app/ai/ranking/page.tsx`
    - `components/{StockCard, PriceChart, ScoreRadarChart, RankingTable}.tsx`
*   **Test Files**: `frontend/__tests__/**`

## 測試案例清單

### 1. 基礎路徑測試 (Happy Path)
#### StockCard 組件
- [x] **TC-1101: 渲染正確性**: StockCard 應正確渲染股票代碼與名稱。
- [x] **TC-1102: 漲幅顏色 (綠)**: StockCard 應根據正數 changePercent 顯示綠色。
- [x] **TC-1103: 跌幅顏色 (紅)**: StockCard 應根據負數 changePercent 顯示紅色。
- [x] **TC-1104: 迷你圖渲染**: StockCard 應正確渲染迷你走勢圖 (sparklineData)。
- [x] **TC-1105: 導航功能**: StockCard 點擊應導航至 /stocks/[symbol]。

#### PriceChart 組件
- [x] **TC-1201: 圖表渲染**: PriceChart 應正確渲染走勢區域圖。
- [x] **TC-1202: 數據量**: PriceChart 應顯示正確的交易日數量。
- [x] **TC-1203: Tooltip**: PriceChart Tooltip 應顯示 OHLC 數據。

#### ScoreRadarChart 組件
- [x] **TC-1301: 雷達圖渲染**: ScoreRadarChart 應正確渲染五維度雷達圖。
- [x] **TC-1302: 平均分**: ScoreRadarChart 應計算並顯示平均評分。
- [x] **TC-1303: 評級顯示**: ScoreRadarChart 評級 (A+/A/B/C/D) 應根據分數正確顯示。

#### RankingTable 組件
- [x] **TC-1401: 列表渲染**: RankingTable 應正確渲染排行數據。
- [x] **TC-1402: 排序互動**: RankingTable 點擊表頭應進行排序。
- [x] **TC-1403: 分頁功能**: RankingTable 分頁功能應正常運作。
- [x] **TC-1404: 行點擊**: RankingTable 行點擊應觸發 onRowClick 回調。

#### 頁面整合
- [x] **TC-1501: 列表頁載入**: /stocks 頁面應正確載入並顯示股票卡片。
- [x] **TC-1502: 列表搜尋**: 搜尋框輸入應正確篩選股票。
- [x] **TC-1503: 市場篩選**: 市場切換按鈕 (全部/台股/美股) 應正確篩選。
- [x] **TC-1601: 詳情頁載入**: /stocks/[symbol] 應正確載入個股數據。
- [x] **TC-1602: 404 處理**: 不存在的 symbol 應顯示「找不到股票」訊息。
- [x] **TC-1603: 返回導航**: 返回按鈕應正確導航至上一頁。
- [x] **TC-1701: 排行頁載入**: /ai/ranking 應正確渲染排行榜。
- [x] **TC-1702: 數據刷新**: 刷新評分按鈕應更新數據。
- [x] **TC-1703: 聯動更新**: 點擊表格行應更新右側雷達圖。
- [x] **TC-1704: 統計卡片**: 統計卡片應顯示正確的平均分與計數。

### 2. 邊界條件測試 (Edge Cases)
- [x] **TC-2101 (StockCard)**: 應處理 changePercent = 0 的情況 (顯示灰色)。
- [x] **TC-2102 (StockCard)**: 應處理空的 sparklineData。
- [x] **TC-2103 (PriceChart)**: 應處理只有 1 個數據點的情況。
- [x] **TC-2104 (ScoreRadarChart)**: 應處理分數為 0 的維度。
- [x] **TC-2105 (RankingTable)**: 應處理空數據陣列。
- [x] **TC-2201 (Search)**: 搜尋框應正確處理特殊字符輸入。
- [x] **TC-2202 (Search)**: 搜尋框應正確處理空格輸入。
- [x] **TC-2203 (URL)**: URL 中的 symbol 應處理大小寫不一致。

### 3. 安全性與數據一致性
- [x] **TC-3101 (Hydration)**: 排行頁 SSR/CSR 數據應完全一致 (無 Hydration 錯誤)。
- [x] **TC-3102 (Randomness)**: 所有頁面不應使用 Math.random() 於頂層模組。
- [x] **TC-3201 (Link Security)**: StockCard Link 應使用正確的 href 格式。
- [x] **TC-3202 (XSS)**: RankingTable Link 應防止 XSS。

### 4. 可訪問性與 UI/UX
- [x] **TC-4001 (Pointer)**: 所有可點擊元素應有 cursor-pointer 樣式。
- [x] **TC-4002 (Hover)**: 排行表格表頭應有 hover 效果。
- [x] **TC-4003 (RWD)**: 頁面在 768px 寬度下應保持可用。
