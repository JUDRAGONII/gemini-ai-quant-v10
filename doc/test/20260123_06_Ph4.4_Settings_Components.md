# 20260123_06_Ph4.4_Settings_Components.md

## 測試目標
驗證 **UI/UX Pro Max** 原子化組件的渲染品質、系統設定模組的高級交互，以及跨組件的一致性。

## 測試環境
- **框架**: Next.js 14, Jest, React Testing Library
- **設計準則**: Glassmorphism, Accessibility (A11y)

## 測試案例清單

### 1. 原子化組件驗證 (UI Primitives)
- [x] **TC-1401**: `ProButton` 應支持 `isLoading` 狀態，且在載入中應禁用點擊並顯示 Spinner（Lucide）。
- [x] **TC-1402**: `GlassCard` 應正確應用 `backdrop-blur` 與透明度疊加效果，且在低配模式下應自動 fallback。
- [x] **TC-1403**: `ProBadge` 應根據傳入的 `status` (success/warning/error) 顯示對應的 HSL 配色。

### 2. 系統設定邏輯 (Settings Logic)
- [x] **TC-5401**: 設定持久化 - 修改 API Key 或 UI 偏好後，重新整理頁面應能保留設定（LocalStorage）。
- [x] **TC-5402**: 設定同步 - 修改全域設定後，主首頁組件應能即時反映變更（Context API）。
- [x] **TC-5403**: `API Masking` - 設定頁面的 API Key 輸入框應預設遮照，點擊「眼睛」圖示後切換為明文。

### 3. 安全性與邊界 (Security & Edge Cases)
- [x] **TC-3401**: 驗證 LocalStorage 不存儲明文密碼（資料庫密碼）。
- [x] **TC-2401**: 當 LocalStorage 損壞時，`SettingsProvider` 應自動回復至預設安全配置（Safe Reset）。

### 4. 高質感交互 (UX Excellence)
- [x] **TC-4401**: 驗證所有互動元素均具有 `cursor-pointer` 屬性。
- [x] **TC-4402**: 驗證組件在 `prefers-reduced-motion` 系統設定下應取消過渡動畫。
