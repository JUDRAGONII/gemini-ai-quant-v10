# 20260128_13_KLineChart_Technical_Validation (K線圖技術分析驗收)

## 1. 測試目標
- 驗證 K線圖組件正確渲染股票價格數據 (Candlestick Chart)。
- 驗證週期切換功能 (1D/1W/1M/3M/6M/1Y/MAX)。
- 驗證技術指標疊加 (MA5/10/20/60/120, RSI, MACD)。
- 驗證圖表互動功能 (縮放、平移、十字游標)。
- 驗證成交量柱狀圖顯示。

## 2. 測試環境
- **OS**: Windows (Localhost)
- **Frontend**: Next.js 14, Tailwind CSS, lightweight-charts v5.1.0
- **Test Date**: 2026-01-28
- **Browser**: Chrome 120+
