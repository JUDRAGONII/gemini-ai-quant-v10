# 20260128_14_Watchlist_Validation (自選股管理功能驗收)

## 1. 測試目標
- 驗證用戶可新增股票至自選股。
- 驗證用戶可從自選股移除股票。
- 驗證自選股清單正確顯示股價與漲跌。
- 驗證 RLS 安全政策。
- 驗證 API 端點功能。

## 2. 測試環境
- **OS**: Windows (Localhost)
- **Frontend**: Next.js 14, Supabase Client
- **Backend**: Supabase PostgreSQL
- **Test Date**: 2026-01-28
- **Browser**: Chrome 120+

## 3. 測試案例清單

### 3.1 基礎路徑 (Happy Path)
- [x] **TC-1400**: 訪問自選股頁面
  - **操作**: 進入 `/watchlist`。
  - **預期**: 頁面正常載入，顯示自選股列表。

- [x] **TC-1401**: 新增股票至自選股
  - **操作**: 輸入股票代碼 2330，點擊查詢，再點擊新增。
  - **預期**: 股票新增成功，顯示於列表中。

- [x] **TC-1402**: 從自選股移除股票
  - **操作**: 點擊股票旁邊的刪除圖標，確認移除。
  - **預期**: 股票從列表中移除。

- [x] **TC-1403**: 顯示即時報價
  - **操作**: 查看自選股列表。
  - **預期**: 顯示最新價格、漲跌百分比。

### 3.2 API 端點測試
- [x] **TC-1410**: GET /api/watchlist
  - **操作**: 發送 GET 請求。
  - **預期**: 返回用戶的自選股清單。

- [x] **TC-1411**: POST /api/watchlist
  - **操作**: 發送 POST 請求，帶 stock_code。
  - **預期**: 股票新增成功，返回新記錄。

- [x] **TC-1412**: DELETE /api/watchlist
  - **操作**: 發送 DELETE 請求，帶 id。
  - **預期**: 股票移除成功。

### 3.3 邊界條件 (Edge Cases)
- [x] **TC-2410**: 新增重複股票
  - **操作**: 將已存在的股票再次新增。
  - **預期**: 顯示「股票已存在」錯誤訊息。

- [x] **TC-2411**: 新增不存在的股票
  - **操作**: 輸入不存在的股票代碼。
  - **預期**: 顯示「股票代碼不存在」錯誤訊息。

- [x] **TC-2412**: 空白輸入處理
  - **操作**: 不輸入股票代碼直接點擊新增。
  - **預期**: 不執行操作或顯示提示。

- [x] **TC-2413**: 空自選股列表
  - **操作**: 尚未新增任何股票。
  - **預期**: 顯示「尚未加入任何股票」提示。

### 3.4 安全性驗證
- [x] **TC-3410**: 未登入用戶訪問

- [x] **TC-3411**: RLS 政策測試

  - **預期**: 用戶 B 無法刪除用戶 A 的股票。
