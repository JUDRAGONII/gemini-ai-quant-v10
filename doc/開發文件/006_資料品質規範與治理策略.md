## 1. 資料品質評估維度 (Quality Dimensions)

| 維度 | 檢核項目 (Checkpoints) | 容忍度 (Tolerance) |
| :--- | :--- | :--- |
| **完整性 (Completeness)** | 核心權值股歷史 K 線不可有連續 3 日以上斷層 | < 0.1% 遺失率 |
| **時效性 (Timeliness)** | 台股收盤後 18:00 前完成當日數據更新 | Delay < 2 hrs |
| **準確性 (Accuracy)** | 價格與 Fugle/TWSE 官方公告落差需為 0 | 0 誤差 |
| **一致性 (Consistency)** | 同一標的在 `daily_price` 與 `stock_factors` 的日期必須對齊 | 100% 對齊 |

## 2. ETL 治理閘防線 (Quality Gates)

### 第一道防線：擷取層 (Ingestion Guard)
*   **BOM 去除**：針對 TAIFEX 等回傳 CSV 帶 BOM 的數據源，強制檢核並去除 `utf-8-sig`。
*   **格式校驗**：若價格欄位回傳非數字（如「--」或「0」），存入資料庫前須改為 `NULL` 避免計算崩潰。

### 第二道防線：寫入層 (Persistence Guard)
*   **PK 衝突判定**：利用 `ON CONFLICT (stock_code, trade_date) DO UPDATE` 確保數據不重複。
*   **市場標籤精確化 (Market Labeling)**：
    - **台股 (TWSE)**：匹配模式 `stock_code ~ '^[0-9]'` (首位為數字，涵蓋 00937B 等股票/ETF)。
    - **美股 (TIINGO)**：匹配模式 `stock_code ~ '^[A-Z]'` 且排除已知期貨代號。
    - **期貨 (TAIFEX)**：顯式定義清單 `('TX', 'MTX', 'TE', 'TFE')`。
*   **異常值偵測**：若當日漲跌幅 > 10.1% (排除除權息) 則自動標記 `is_valid = false` 並觸發告警。

### 第三道防線：清理層 (Post-Processing)
*   **缺漏補洞**：每月執行 `backfill_audit` 腳本，識別資料庫中的時間空洞並自動重啟 `BackfillTask`。

## 3. 資料治理組織與告警

1.  **權責劃分**：AI Worker 負責自動修補，管理員負責人工覆核異常回報。
2.  **溝通管道**：重大數據異常 (如 FRED 連線失敗) 由系統自動推送 **Telegram Bot** 訊息。
