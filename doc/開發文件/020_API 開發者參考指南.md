## 第一章：API 總覽

### 1.1 歡迎使用 AI 投資分析儀 API

本指南為開發者提供 AI 投資分析儀 V10.0 RESTful API 的完整參考資訊，協助您快速整合系統功能到您的應用程式中。API 基於 REST 架構設計，採用標準 HTTP 協定的請求與響應格式，回傳資料使用 JSON 編碼。

AI 投資分析儀 API 提供以下主要功能：行情數據查詢（台股、美股、期貨）、宏觀經濟指標查詢、籌碼數據查詢、AI 投資評分與報告查詢、投資組合管理。所有 API 端點皆受到 API Key 認證保護，確保數據存取的安全性与可控性。

### 1.2 快速開始

開始使用 API 前，您需要完成以下準備工作：

首先，申請 API Key。聯繫系統管理員為您建立 API Key。每個 API Key 可設定不同的權限範圍，支援精細化的存取控制。

其次，確認 API 伺服器位址。API 服務預設監聽 8000 端口，基礎路徑為 `/api/v1/`。完整 API 端點 URL 格式為：`https://your-nas-ip:8000/api/v1/{endpoint}`。

第三，選擇 HTTP 客戶端。您可以使用任何支援 HTTP 請求的程式語言或工具。建議使用具備完善 HTTP 客戶端功能的語言，如 Python（requests）、JavaScript（axios/fetch）、Go（net/http）。

### 1.3 基礎使用範例

以下使用 Python requests 庫展示 API 調用的基本模式：

```python
import requests
import json

# API 基礎設定
BASE_URL = "https://your-nas-ip:8000/api/v1"
API_KEY = "your_api_key_here"

# 設定請求 Headers
headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json",
    "Accept": "application/json"
}

# 呼叫 API - 取得股票清單
def get_stocks(page=1, per_page=20):
    url = f"{BASE_URL}/stocks"
    params = {"page": page, "per_page": per_page}
    response = requests.get(url, headers=headers, params=params)
    response.raise_for_status()
    return response.json()

# 呼叫 API - 取得個股行情
def get_stock_prices(stock_code, start_date, end_date):
    url = f"{BASE_URL}/stocks/{stock_code}/prices"
    params = {"start_date": start_date, "end_date": end_date}
    response = requests.get(url, headers=headers, params=params)
    response.raise_for_status()
    return response.json()

# 呼叫 API - 取得 AI 評分
def get_ai_score(stock_code):
    url = f"{BASE_URL}/ai/scores/{stock_code}"
    response = requests.get(url, headers=headers)
    response.raise_for_status()
    return response.json()

# 使用範例
if __name__ == "__main__":
    # 取得股票清單
    stocks = get_stocks()
    print(f"取得 {len(stocks['data'])} 檔股票")

    # 取得特定股票行情
    prices = get_stock_prices("2330", "2026-01-01", "2026-01-31")
    print(prices)

    # 取得 AI 評分
    score = get_ai_score("2330")
    print(f"AI 評分: {score['data']['composite_score']}")
```

## 第二章：認證與授權

### 2.1 API Key 認證

AI 投資分析儀 API 使用 API Key 進行身份認證。在每次請求時，請在 HTTP Header 中加入 `Authorization` 欄位，格式為 `Bearer {YOUR_API_KEY}`。

```http
GET /api/v1/stocks HTTP/1.1
Host: your-nas-ip:8000
Authorization: Bearer sk_test_51abc123def456ghi789jklmno0
Accept: application/json
```

API Key 可透過系統管理介面建立。每個 Key 可設定以下屬性：Key 名稱與說明、有效期限（可選）、權限範圍（可調用哪些 API）、速率限制（每分鐘可請求次數）。

### 2.2 錯誤響應：認證失敗

若 API Key 無效、過期或未提供，伺服器將返回 401 Unauthorized 錯誤：

```json
{
  "status": "error",
  "error": {
    "code": "40101",
    "message": "Invalid or missing authentication token",
    "details": {
      "reason": "API key expired"
    }
  },
  "timestamp": "2026-01-27T10:30:00Z"
}
```

### 2.3 權限控制

部分 API 端點需要特定權限才能存取。例如，寫入類型的端點（如投資組合管理）需要 `write` 權限。若權限不足，伺服器將返回 403 Forbidden 錯誤：

```json
{
  "status": "error",
  "error": {
    "code": "40301",
    "message": "Insufficient permissions",
    "details": {
      "required": ["read", "write"],
      "current": ["read"]
    }
  },
  "timestamp": "2026-01-27T10:30:00Z"
}
```

## 第四章：錯誤處理

### 4.1 錯誤響應格式

所有錯誤響應遵循統一格式：

```json
{
  "status": "error",
  "error": {
    "code": "40001",
    "message": "Error message description",
    "details": {
      "field": "Additional error details"
    }
  },
  "timestamp": "2026-01-27T10:30:00Z"
}
```

### 4.2 錯誤碼清單

| HTTP 狀態碼 | 錯誤碼 | 說明 |
|-------------|--------|------|
| 400 | 40001 | 請求參數錯誤 |
| 400 | 40002 | 請求格式錯誤 |
| 400 | 40003 | 參數驗證失敗 |
| 401 | 40101 | 無效或缺少 API Key |
| 401 | 40102 | API Key 已過期 |
| 403 | 40301 | 權限不足 |
| 403 | 40302 | 速率限制超標 |
| 404 | 40401 | 資源不存在 |
| 404 | 40402 | 端點不存在 |
| 429 | 42901 | 請求過於頻繁 |
| 500 | 50001 | 伺服器內部錯誤 |
| 503 | 50301 | 服務暫時不可用 |

### 4.3 重試策略

當收到 5xx 錯誤或 429 速率限制時，建議採用指數退避（Exponential Backoff）策略重試：

```python
import time
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

def retry_request(url, headers, max_retries=3):
    session = requests.Session()
    retry_strategy = Retry(
        total=max_retries,
        backoff_factor=1,
        status_forcelist=[429, 500, 502, 503, 504]
    )
    adapter = HTTPAdapter(max_retries=retry_strategy)
    session.mount("http://", adapter)
    session.mount("https://", adapter)
    
    for attempt in range(max_retries):
        try:
            response = session.get(url, headers=headers)
            if response.status_code not in [429, 500, 502, 503, 504]:
                return response.json()
        except requests.exceptions.RequestException:
            pass
        
        if attempt < max_retries - 1:
            wait_time = (2 ** attempt)
            time.sleep(wait_time)
    
    return None
```

## 第五章：速率限制

### 5.1 速率限制政策

API 請求受到速率限制，預設限制為每分鐘 60 次請求。速率限制以 API Key 為單位計算，同時發送多個請求時會共享配額。

當速率限制即將達到時，響應 Header 會包含以下資訊：

| Header | 說明 |
|--------|------|
| X-RateLimit-Limit | 當前時間窗口的配額上限 |
| X-RateLimit-Remaining | 剩餘可請求次數 |
| X-RateLimit-Reset | 配額重置的 Unix 時間戳 |

### 5.2 速率限制超標

當請求超過速率限制時，伺服器返回 429 Too Many Requests 錯誤：

```http
HTTP/1.1 429 Too Many Requests
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 0
X-RateLimit-Reset: 1706349600
Retry-After: 30
```

響應 Body：

```json
{
  "status": "error",
  "error": {
    "code": "42901",
    "message": "Rate limit exceeded. Please retry after 30 seconds.",
    "details": {
      "retry_after": 30
    }
  },
  "timestamp": "2026-01-27T10:30:00Z"
}
```

請依據 `Retry-After` 欄位指示等待後再重試請求。

### 6.1 Python SDK

```python
# ai_investor_sdk.py

import requests
from typing import List, Dict, Optional

class AIInvestorAPI:
    def __init__(self, api_key: str, base_url: str = "http://localhost:8000/api/v1"):
        self.api_key = api_key
        self.base_url = base_url
        self.headers = {
            "Authorization": f"Bearer {api_key}",
            "Content-Type": "application/json",
            "Accept": "application/json"
        }
    
    def _request(self, method: str, endpoint: str, **kwargs) -> Dict:
        url = f"{self.base_url}/{endpoint}"
        response = requests.request(method, url, headers=self.headers, **kwargs)
        response.raise_for_status()
        return response.json()
    
    def get_stocks(self, page: int = 1, per_page: int = 20, market: str = None) -> Dict:
        params = {"page": page, "per_page": per_page}
        if market:
            params["market"] = market
        return self._request("GET", "stocks", params=params)
    
    def get_stock_prices(self, stock_code: str, start_date: str, end_date: str, 
                         interval: str = "daily") -> Dict:
        params = {
            "start_date": start_date,
            "end_date": end_date,
            "interval": interval
        }
        return self._request("GET", f"stocks/{stock_code}/prices", params=params)
    
    def get_quote(self, stock_code: str) -> Dict:
        return self._request("GET", f"stocks/{stock_code}/quote")
    
    def get_ai_score(self, stock_code: str) -> Dict:
        return self._request("GET", f"ai/scores/{stock_code}")
    
    def get_ai_scores_ranking(self, market: str = None, limit: int = 50) -> Dict:
        params = {"per_page": limit}
        if market:
            params["market"] = market
        return self._request("GET", "ai/scores", params=params)
    
    def get_macro_indicators(self, country: str = None, 
                            category: str = None) -> Dict:
        params = {}
        if country:
            params["country"] = country
        if category:
            params["category"] = category
        return self._request("GET", "macro/indicators", params=params)
    
    def get_macro_indicator(self, indicator_code: str, start_date: str, 
                           end_date: str, transformation: str = "level") -> Dict:
        params = {
            "start_date": start_date,
            "end_date": end_date,
            "transformation": transformation
        }
        return self._request("GET", f"macro/indicators/{indicator_code}", params=params)
    
    def get_institution_chips(self, stock_code: str, start_date: str, 
                              end_date: str) -> Dict:
        params = {
            "stock_code": stock_code,
            "start_date": start_date,
            "end_date": end_date
        }
        return self._request("GET", "chips/institution", params=params)
    
    def semantic_search(self, query: str, limit: int = 5) -> Dict:
        params = {"query": query, "limit": limit}
        return self._request("GET", "ai/search", params=params)
```

```javascript
// ai-investor-sdk.js

class AIInvestorAPI {
  constructor(apiKey, baseUrl = 'http://localhost:8000/api/v1') {
    this.apiKey = apiKey;
    this.baseUrl = baseUrl;
    this.headers = {
      'Authorization': `Bearer ${apiKey}`,
      'Content-Type': 'application/json',
      'Accept': 'application/json'
    };
  }

  async _request(endpoint, options = {}) {
    const url = `${this.baseUrl}/${endpoint}`;
    const response = await fetch(url, {
      ...options,
      headers: { ...this.headers, ...options.headers }
    });
    
    if (!response.ok) {
      const error = await response.json();
      throw new Error(error.error?.message || 'Request failed');
    }
    
    return response.json();
  }

  async getStocks(page = 1, perPage = 20, market = null) {
    const params = new URLSearchParams({ page, per_page: perPage });
    if (market) params.append('market', market);
    return this._request(`stocks?${params}`);
  }

  async getStockPrices(stockCode, startDate, endDate, interval = 'daily') {
    const params = new URLSearchParams({
      start_date: startDate,
      end_date: endDate,
      interval
    });
    return this._request(`stocks/${stockCode}/prices?${params}`);
  }

  async getQuote(stockCode) {
    return this._request(`stocks/${stockCode}/quote`);
  }

  async getAIScore(stockCode) {
    return this._request(`ai/scores/${stockCode}`);
  }

  async getAIScoresRanking(market = null, limit = 50) {
    const params = new URLSearchParams({ per_page: limit });
    if (market) params.append('market', market);
    return this._request(`ai/scores?${params}`);
  }

  async semanticSearch(query, limit = 5) {
    const params = new URLSearchParams({ query, limit });
    return this._request(`ai/search?${params}`);
  }
}

module.exports = AIInvestorAPI;
```
