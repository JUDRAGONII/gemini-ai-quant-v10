## 1. 數據擷取模組 (ETL & Market Data)

### 1.1 行情數據 (`/daily_price`)
*   **GET**: 檢索歷史日線數據。
    *   `stock_code`: 標的代號 (e.g., `eq.2330` or `in.(AAPL,TSLA)`)
    *   `trade_date`: 交易日期
*   **POST/PATCH**: 僅限系統管理員 (`service_role`) 寫入。

### 1.2 宏觀指標 (`/macro_indicators`)
*   **GET**: 檢索全球經濟數據。
    *   `indicator_code`: e.g., `eq.FEDFUNDS`
    *   `country`: e.g., `eq.US`

### 1.3 個股詳情聚合 API (`/api/stocks/{symbol}`) [NEW]
獲取指定標的的詳情數據，包含基礎資料、財務指標與歷史價格序列。

*   **請求參數**:
    - `params.symbol`: 股票代號 (e.g., `2330.TW`)
    - `query.period`: `1D`, `1W`, `1M`, `1Y`, `MAX` (預設 `1Y`)
*   **數據契約**:
    - `metadata`: 基礎標的資訊映射自 `stocks` 表。
    - `price_series`: 時序數據，`time` 採 **UNIX Timestamp (Seconds)**。
*   **安全**: 支援 `ANON` 權限讀取。

## 2. 量化分析與 AI 決策模組

### 2.1 量化因子 (`/stock_factors`) [CRITICAL]
*   **GET**: 獲取標的多維度評分。
    *   `composite_score`: 依分數高低排序篩選潛力標的。
*   **計算觸發**: 由 AI Worker 透過 `pg_cron` 定期更新，不開放前端直接修改。

### 2.2 AI 報告 (`/ai_reports`)
*   **GET**: 取得投資分析報告。
    *   可搭配向量搜尋函數 `rpc/match_reports` 進行語義檢索。
*   **屬性**: 包含 `summary`, `full_content`, `embedding`。

## 3. 系統管理與 Rpc 函數 (`/rpc/`)

為了封裝複雜邏輯，系統定義了以下資料庫函數：

| 函數名稱 | 說明 | 參數範例 |
| :--- | :--- | :--- |
| `get_evolution_fitness` | 計算目前基因組的適應度 | `{"user_id": "uuid"}` |
| `match_reports` | 餘弦相似度向量檢索 | `{"query_embedding": [...], "match_threshold": 0.5}` |
| `get_backfill_progress` | 獲取數據回補百分比進度 | 無 |

## 4. 身份認證與用戶 API (`/auth/v1/`)

由 Supabase GoTrue 託管：
*   `/login`: 請求 JWT 令牌。
*   `/user`: 取得當前登入用戶資訊。
*   `/token`: 刷新過期令牌。
