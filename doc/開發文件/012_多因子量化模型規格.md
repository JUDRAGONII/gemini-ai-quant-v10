## 第一章：量化模型總覽

### 1.1 模型設計理念

多因子量化模型是 AI 投資分析儀 V10.0 的核心評分引擎，負責將複雜的投資評估轉化為客觀、可比較的數值評分。模型採用「四維度因子評分」（Value-Growth-Quality-Momentum，簡稱 VQGM）架構，結合宏觀調節係數，產生綜合投資評分。

本模型的設計理念源自現代投資組合理論（MPT）與行為金融學的研究成果。模型認為，股票的長期報酬由多重因子共同驅動，單一維度的分析容易產生偏差。透過系統性地評估價值、成長、品質、動能四個核心維度，並根據宏觀環境動態調整權重，模型能夠產生更為全面、穩健的投資評估。

### 1.2 因子維度架構

| 維度 | 代號 | 核心假說 | 主要指標 |
|------|------|----------|----------|
| 價值 | V | 被低估的股票終將回歸合理價值 | PE、PB、殖利率 |
| 成長 | G | 高成長公司創造更高報酬 | 營收成長率、EPS 成長率 |
| 品質 | Q | 優質公司具備更強的獲利持續性 | ROE、毛利率、槓桿率 |
| 動能 | M | 價格趨勢具有持續性 | 相對強弱、價格動能 |
| 宏觀 | Macro | 宏觀環境影響因子有效性 | 利率環境、景氣循環 |

## 第二章：價值因子 (Value Factor)

### 2.1 因子定義與計算

價值因子評估股票相對於其基本面價值是否被低估。系統計算四項核心價值指標：

**本益比因子 (PE Score)**

$$ PE\_score = 100 \times (1 - Percentile(PE_{stock}, PE_{all\_stocks})) $$

說明：本益比越低，Percentile 越小，評分越高。

**股價淨值比因子 (PB Score)**

$$ PB\_score = 100 \times (1 - Percentile(PB_{stock}, PB_{all\_stocks})) $$

說明：股價淨值比越低，Percentile 越小，評分越高。

**殖利率因子 (Dividend Yield Score)**

$$ DY\_score = 100 \times Percentile(DY_{stock}, DY_{all\_stocks}) $$

說明：殖利率越高，Percentile 越大，評分越高。

**EV/EBITDA 因子 (EV/EBITDA Score)**

$$ EVEBITDA\_score = 100 \times (1 - Percentile(EVEBITDA_{stock}, EVEBITDA_{all\_stocks})) $$

### 2.2 價值維度聚合

$$ Value\_score = \frac{PE\_score \times w_{PE} + PB\_score \times w_{PB} + DY\_score \times w_{DY} + EVEBITDA\_score \times w_{EVEBITDA}}{w_{PE} + w_{PB} + w_{DY} + w_{EVEBITDA}} $$

預設權重：$w_{PE} = 0.35, w_{PB} = 0.30, w_{DY} = 0.20, w_{EVEBITDA} = 0.15$

### 2.3 邊界條件與調整

| 指標 | 最小值 | 最大值 | 異常處理 |
|------|--------|--------|----------|
| PE | 0 | 100 | PE < 0 或 PE > 100 視為異常，設為中位數 |
| PB | 0 | 20 | PB < 0 或 PB > 20 視為異常，設為中位數 |
| DY | 0% | 15% | DY < 0% 或 DY > 15% 視為異常，設為中位數 |
| EV/EBITDA | 0 | 50 | 異常值同上處理 |

### 2.4 程式碼實現

```python
# factors/value_factor.py

import pandas as pd
import numpy as np
from typing import Dict, Tuple

class ValueFactor:
    def __init__(self, weights: Dict[str, float] = None):
        self.default_weights = {
            'pe': 0.35,
            'pb': 0.30,
            'dividend_yield': 0.20,
            'ev_ebitda': 0.15
        }
        self.weights = weights or self.default_weights
    
    def calculate(self, financial_data: pd.DataFrame) -> pd.DataFrame:
        """
        計算價值因子評分
        
        Args:
            financial_data: 包含 PE, PB, Dividend Yield, EV/EBITDA 的 DataFrame
        
        Returns:
            包含價值評分的 DataFrame
        """
        result = financial_data.copy()
        
        # 異常值處理
        result['pe'] = self._clip_pe(result['pe'])
        result['pb'] = self._clip_pb(result['pb'])
        result['dividend_yield'] = self._clip_dy(result['dividend_yield'])
        result['ev_ebitda'] = self._clip_evebitda(result['ev_ebitda'])
        
        # 計算單因子評分（Percentile 方法）
        result['pe_score'] = self._percentile_score(result['pe'], lower_is_better=True)
        result['pb_score'] = self._percentile_score(result['pb'], lower_is_better=True)
        result['dy_score'] = self._percentile_score(result['dividend_yield'], lower_is_better=False)
        result['ev_ebitda_score'] = self._percentile_score(result['ev_ebitda'], lower_is_better=True)
        
        # 計算維度評分
        result['value_score'] = (
            result['pe_score'] * self.weights['pe'] +
            result['pb_score'] * self.weights['pb'] +
            result['dy_score'] * self.weights['dividend_yield'] +
            result['ev_ebitda_score'] * self.weights['ev_ebitda']
        ) / sum(self.weights.values())
        
        return result[['stock_code', 'pe_score', 'pb_score', 'dy_score', 
                       'ev_ebitda_score', 'value_score']]
    
    def _percentile_score(self, series: pd.Series, lower_is_better: bool) -> pd.Series:
        """將數值轉換為 Percentile 評分 (0-100)"""
        percentile = series.rank(pct=True) * 100
        if lower_is_better:
            return 100 - percentile
        return percentile
    
    def _clip_pe(self, pe: pd.Series) -> pd.Series:
        return pe.clip(lower=0, upper=100)
    
    def _clip_pb(self, pb: pd.Series) -> pd.Series:
        return pb.clip(lower=0, upper=20)
    
    def _clip_dy(self, dy: pd.Series) -> pd.Series:
        return dy.clip(lower=0, upper=0.15)
    
    def _clip_evebitda(self, evebitda: pd.Series) -> pd.Series:
        return evebitda.clip(lower=0, upper=50)
```

## 第三章：成長因子 (Growth Factor)

### 3.1 因子定義與計算

成長因子評估公司的營收與獲利成長動能。高成長公司通常具備更強的創造價值能力，但需注意成長的品質與持續性。

**營收成長率因子 (Revenue Growth Score)**

$$ RevGrowth\_score = Percentile(RevenueGrowth_{stock}, RevenueGrowth_{all\_stocks}) $$

**EPS 成長率因子 (EPS Growth Score)**

$$ EPSGrowth\_score = Percentile(EPSGrowth_{stock}, EPSGrowth_{all\_stocks}) $$

**獲利成長穩定性因子 (Earnings Stability Score)**

計算最近 8 季 EPS 的變異係數，變異係數越低表示獲利越穩定：

$$ CV = \frac{\sigma(EPS)}{\mu(EPS)} $$

$$ Stability\_score = 100 - Percentile(CV_{stock}, CV_{all\_stocks}) $$

### 3.2 成長維度聚合

$$ Growth\_score = \frac{RevGrowth\_score \times w_{rev} + EPSGrowth\_score \times w_{eps} + Stability\_score \times w_{stability}}{w_{rev} + w_{eps} + w_{stability}} $$

預設權重：$w_{rev} = 0.40, w_{eps} = 0.40, w_{stability} = 0.20$

### 3.3 成長品質調整

為避免追求成長而忽略品質，系統實施以下調整：

```python
def _growth_quality_adjustment(self, growth_score: float, 
                                roe: float, 
                                leverage: float) -> float:
    """成長評分的品質調整"""
    # ROE 低於 10% 的公司，成長評分打 9 折
    if roe < 0.10:
        growth_score *= 0.9
    
    # 槓桿率過高的公司，成長評分打 8 折
    if leverage > 2.0:
        growth_score *= 0.8
    
    return growth_score
```

## 第四章：品質因子 (Quality Factor)

### 4.1 因子定義與計算

品質因子評估公司的獲利能力與財務結構穩健性。優質公司通常能夠在各種市場環境下維持穩定的獲利。

**ROE 因子 (Return on Equity Score)**

$$ ROE\_score = Percentile(ROE_{stock}, ROE_{all\_stocks}) $$

**毛利率因子 (Gross Margin Score)**

$$ GM\_score = Percentile(GrossMargin_{stock}, GrossMargin_{all\_stocks}) $$

**淨利率因子 (Net Margin Score)**

$$ NM\_score = Percentile(NetMargin_{stock}, NetMargin_{all\_stocks}) $$

**槓桿率因子 (Leverage Score)**

使用資產負債率，槓桿越低評分越高：

$$ Leverage\_score = 100 - Percentile(Leverage_{stock}, Leverage_{all\_stocks}) $$

**現金流/營收比因子 (OCF Ratio Score)**

$$ OCF\_score = Percentile(OCFToRevenue_{stock}, OCFToRevenue_{all\_stocks}) $$

### 4.2 品質維度聚合

$$ Quality\_score = \frac{ROE\_score \times w_{roe} + GM\_score \times w_{gm} + NM\_score \times w_{nm} + Leverage\_score \times w_{lev} + OCF\_score \times w_{ocf}}{w_{roe} + w_{gm} + w_{nm} + w_{lev} + w_{ocf}} $$

預設權重：$w_{roe} = 0.30, w_{gm} = 0.20, w_{nm} = 0.20, w_{lev} = 0.15, w_{ocf} = 0.15$

### 4.3 品質因子程式碼

```python
# factors/quality_factor.py

import pandas as pd
import numpy as np

class QualityFactor:
    def __init__(self, weights: Dict[str, float] = None):
        self.default_weights = {
            'roe': 0.30,
            'gross_margin': 0.20,
            'net_margin': 0.20,
            'leverage': 0.15,
            'ocf_ratio': 0.15
        }
        self.weights = weights or self.default_weights
    
    def calculate(self, financial_data: pd.DataFrame) -> pd.DataFrame:
        result = financial_data.copy()
        
        # 異常值處理
        result['roe'] = result['roe'].clip(lower=-50, upper=100)
        result['gross_margin'] = result['gross_margin'].clip(lower=0, upper=100)
        result['net_margin'] = result['net_margin'].clip(lower=-50, upper=100)
        result['leverage'] = result['leverage'].clip(lower=0, upper=10)
        result['ocf_ratio'] = result['ocf_ratio'].clip(lower=-1, upper=2)
        
        # 計算單因子評分
        result['roe_score'] = self._percentile_score(result['roe'])
        result['gm_score'] = self._percentile_score(result['gross_margin'])
        result['nm_score'] = self._percentile_score(result['net_margin'])
        result['leverage_score'] = 100 - self._percentile_score(result['leverage'])
        result['ocf_score'] = self._percentile_score(result['ocf_ratio'])
        
        # 計算維度評分
        total_weight = sum(self.weights.values())
        result['quality_score'] = (
            result['roe_score'] * self.weights['roe'] +
            result['gm_score'] * self.weights['gross_margin'] +
            result['nm_score'] * self.weights['net_margin'] +
            result['leverage_score'] * self.weights['leverage'] +
            result['ocf_score'] * self.weights['ocf_ratio']
        ) / total_weight
        
        return result[['stock_code', 'roe_score', 'gm_score', 'nm_score',
                       'leverage_score', 'ocf_score', 'quality_score']]
    
    def _percentile_score(self, series: pd.Series) -> pd.Series:
        return series.rank(pct=True) * 100
```

## 第五章：動能因子 (Momentum Factor)

### 5.1 因子定義與計算

動能因子評估股價的價格趨勢與相對強度。動能效應是金融市場中已被廣泛驗證的異象，認為過去表現較好的股票在未來一段時間內傾向於繼續表現較好。

**相對強度因子 (Relative Strength Score)**

$$ RS\_score = Percentile(\frac{Price_{current}}{MA_{250}}, \frac{Price_{all}}{MA_{250\_all}}) $$

**價格動能因子 (Price Momentum Score)**

計算過去 6 個月的累積報酬：

$$ Momentum\_6M = \frac{Price_{today} - Price_{6M\_ago}}{Price_{6M\_ago}} $$

$$ Momentum\_score = Percentile(Momentum\_6M_{stock}, Momentum\_6M_{all\_stocks}) $$

**RSI 因子 (RSI Score)**

$$ RSI\_score = Percentile(RSI_{14}, RSI_{all\_stocks}) $$

**成交量動能因子 (Volume Momentum Score)**

近期成交量相對於歷史平均的變化：

$$ VolMomentum = \frac{AvgVolume_{20d}}{AvgVolume_{200d}} $$

$$ VolScore = Percentile(VolMomentum_{stock}, VolMomentum_{all\_stocks}) $$

### 5.2 動能維度聚合

$$ Momentum\_score = \frac{RS\_score \times w_{rs} + Momentum\_score \times w_{mom} + RSI\_score \times w_{rsi} + VolScore \times w_{vol}}{w_{rs} + w_{mom} + w_{rsi} + w_{vol}} $$

預設權重：$w_{rs} = 0.30, w_{mom} = 0.35, w_{rsi} = 0.20, w_{vol} = 0.15$

### 5.3 動量反轉風險控制

為避免在動能反轉時遭受重大損失，系統實施以下控制：

```python
def _momentum_reversal_check(self, momentum_data: Dict) -> float:
    """檢查動能是否存在反轉風險"""
    risk_penalty = 0
    
    # RSI 過高（超過 80）可能意味著超買
    if momentum_data['rsi'] > 80:
        risk_penalty += 5
    
    # 價格遠離均線（超過 50%）可能存在回調風險
    price_ma_ratio = momentum_data['price'] / momentum_data['ma50']
    if price_ma_ratio > 1.5:
        risk_penalty += (price_ma_ratio - 1.5) * 10
    
    # 成交量萎縮但價格上漲（量價背離）
    if momentum_data['vol_ratio'] < 0.7 and momentum_data['momentum_1m'] > 0.05:
        risk_penalty += 5
    
    return risk_penalty
```

## 第六章：宏觀調節係數

### 6.1 宏觀環境判斷

系統根據宏觀指標動態調整各因子維度的權重，實現「Risk-On」與「Risk-Off」情境下的策略適配：

| 宏觀指標 | Risk-On 條件 | Risk-Off 條件 |
|----------|--------------|---------------|
| VIX 指數 | < 20 | > 30 |
| 美國 10 年公債殖利率 | < 4% | > 5% |
| 信用利差 | < 100bp | > 200bp |
| 製造業 PMI | > 50 | < 45 |

### 6.2 宏觀權重調整公式

$$ Weight_{V}' = Weight_{V} \times (1 + MacroAdj_{V}) $$

$$ MacroAdj_{V} = \begin{cases} 
-0.2 & \text{Risk-On, 價值權重下調} \\
+0.2 & \text{Risk-Off, 價值權重上調}
\end{cases} $$

**Risk-On 環境權重調整**：

| 維度 | 正常權重 | Risk-On 權重 | 調整幅度 |
|------|----------|--------------|----------|
| 價值 | 0.20 | 0.15 | -25% |
| 成長 | 0.25 | 0.30 | +20% |
| 品質 | 0.25 | 0.20 | -20% |
| 動能 | 0.15 | 0.25 | +67% |
| 宏觀 | 0.15 | 0.10 | -33% |

**Risk-Off 環境權重調整**：

| 維度 | 正常權重 | Risk-Off 權重 | 調整幅度 |
|------|----------|--------------|----------|
| 價值 | 0.20 | 0.30 | +50% |
| 成長 | 0.25 | 0.15 | -40% |
| 品質 | 0.25 | 0.35 | +40% |
| 動能 | 0.15 | 0.05 | -67% |
| 宏觀 | 0.15 | 0.15 | 0% |

### 6.3 宏觀調節實現

```python
# factors/macro_adjustment.py

class MacroAdjuster:
    def __init__(self):
        self.risk_indicators = {
            'vix': {'threshold_low': 20, 'threshold_high': 30},
            'bond_yield': {'threshold_low': 0.04, 'threshold_high': 0.05},
            'credit_spread': {'threshold_low': 0.01, 'threshold_high': 0.02},
            'pmi': {'threshold_low': 45, 'threshold_high': 50}
        }
    
    def get_macro_regime(self, macro_data: Dict) -> str:
        """判斷當前宏觀環境"""
        risk_on_count = 0
        risk_off_count = 0
        
        if macro_data.get('vix', 25) < self.risk_indicators['vix']['threshold_low']:
            risk_on_count += 1
        elif macro_data.get('vix', 25) > self.risk_indicators['vix']['threshold_high']:
            risk_off_count += 1
        
        if macro_data.get('bond_yield', 0.045) < self.risk_indicators['bond_yield']['threshold_low']:
            risk_on_count += 1
        elif macro_data.get('bond_yield', 0.045) > self.risk_indicators['bond_yield']['threshold_high']:
            risk_off_count += 1
        
        if macro_data.get('pmi', 50) > self.risk_indicators['pmi']['threshold_high']:
            risk_on_count += 1
        elif macro_data.get('pmi', 50) < self.risk_indicators['pmi']['threshold_low']:
            risk_off_count += 1
        
        if risk_on_count >= 2:
            return 'RISK_ON'
        elif risk_off_count >= 2:
            return 'RISK_OFF'
        else:
            return 'NEUTRAL'
    
    def adjust_weights(self, base_weights: Dict, macro_regime: str) -> Dict:
        """根據宏觀環境調整權重"""
        if macro_regime == 'RISK_ON':
            return {
                'value': base_weights['value'] * 0.75,
                'growth': base_weights['growth'] * 1.20,
                'quality': base_weights['quality'] * 0.80,
                'momentum': base_weights['momentum'] * 1.67,
                'macro': base_weights['macro'] * 0.67
            }
        elif macro_regime == 'RISK_OFF':
            return {
                'value': base_weights['value'] * 1.50,
                'growth': base_weights['growth'] * 0.60,
                'quality': base_weights['quality'] * 1.40,
                'momentum': base_weights['momentum'] * 0.33,
                'macro': base_weights['macro'] * 1.00
            }
        else:
            return base_weights
```

## 第七章：綜合評分計算

### 7.1 評分公式

$$ Composite\_score = \sum_{i=1}^{5} (Dim\_score_i \times Adj\_weight_i) $$

其中 $Dim\_score_i$ 為各維度評分，$Adj\_weight_i$ 為經宏觀調整後的權重。

### 7.2 評分分布與詮釋

| 評分區間 | 評級 | 說明 |
|----------|------|------|
| 85-100 | A | 極度投資價值 |
| 70-84 | B+ | 高度投資價值 |
| 55-69 | B | 中度投資價值 |
| 40-54 | C+ | 偏低投資價值 |
| 25-39 | C | 有限投資價值 |
| 0-24 | D | 缺乏投資價值 |

### 7.3 程式碼整合

```python
# factors/factor_service.py

from typing import Dict, Tuple
import pandas as pd

class FactorService:
    def __init__(self, config: Dict):
        self.config = config
        self.value_factor = ValueFactor()
        self.growth_factor = GrowthFactor()
        self.quality_factor = QualityFactor()
        self.momentum_factor = MomentumFactor()
        self.macro_adjuster = MacroAdjuster()
    
    def calculate_scores(self, stock_data: Dict, macro_data: Dict = None) -> Dict:
        """
        計算股票綜合評分
        
        Args:
            stock_data: 包含所有因子所需數據的字典
            macro_data: 宏觀環境數據（可選）
        
        Returns:
            完整的評分結果
        """
        # 計算各維度評分
        value_scores = self.value_factor.calculate(stock_data['financials'])
        growth_scores = self.growth_factor.calculate(stock_data['financials'])
        quality_scores = self.quality_factor.calculate(stock_data['financials'])
        momentum_scores = self.momentum_factor.calculate(stock_data['technicals'])
        
        # 取得宏觀環境
        macro_regime = 'NEUTRAL'
        if macro_data:
            macro_regime = self.macro_adjuster.get_macro_regime(macro_data)
        
        # 調整權重
        base_weights = {
            'value': 0.20,
            'growth': 0.25,
            'quality': 0.25,
            'momentum': 0.15,
            'macro': 0.15
        }
        adjusted_weights = self.macro_adjuster.adjust_weights(base_weights, macro_regime)
        
        # 計算綜合評分
        composite_score = (
            value_scores['value_score'] * adjusted_weights['value'] +
            growth_scores['growth_score'] * adjusted_weights['growth'] +
            quality_scores['quality_score'] * adjusted_weights['quality'] +
            momentum_scores['momentum_score'] * adjusted_weights['momentum'] +
            stock_data.get('macro_score', 50) * adjusted_weights['macro']
        )
        
        return {
            'stock_code': stock_data['stock_code'],
            'composite_score': round(composite_score, 1),
            'rating': self._get_rating(composite_score),
            'value_score': round(value_scores['value_score'], 1),
            'growth_score': round(growth_scores['growth_score'], 1),
            'quality_score': round(quality_scores['quality_score'], 1),
            'momentum_score': round(momentum_scores['momentum_score'], 1),
            'macro_score': stock_data.get('macro_score', 50),
            'macro_regime': macro_regime,
            'factor_contribution': {
                'value': round(value_scores['value_score'] * adjusted_weights['value'], 1),
                'growth': round(growth_scores['growth_score'] * adjusted_weights['growth'], 1),
                'quality': round(quality_scores['quality_score'] * adjusted_weights['quality'], 1),
                'momentum': round(momentum_scores['momentum_score'] * adjusted_weights['momentum'], 1),
                'macro': round(stock_data.get('macro_score', 50) * adjusted_weights['macro'], 1)
            },
            'calculated_at': pd.Timestamp.now().isoformat()
        }
    
    def _get_rating(self, score: float) -> str:
        if score >= 85:
            return 'A'
        elif score >= 70:
            return 'B+'
        elif score >= 55:
            return 'B'
        elif score >= 40:
            return 'C+'
        elif score >= 25:
            return 'C'
        else:
            return 'D'
```

```python
# factors/data_quality.py

class FactorDataQuality:
    def __init__(self):
        self.quality_rules = {
            'pe': {'min': 0, 'max': 100, 'null_handling': 'use_median'},
            'pb': {'min': 0, 'max': 20, 'null_handling': 'use_median'},
            'roe': {'min': -50, 'max': 100, 'null_handling': 'use_median'},
            'revenue_growth': {'min': -100, 'max': 500, 'null_handling': 'use_median'}
        }
    
    def validate_factor_data(self, factor_data: pd.DataFrame) -> Tuple[pd.DataFrame, Dict]:
        """驗證因子數據品質，回傳清洗後數據與品質報告"""
        quality_report = {
            'total_records': len(factor_data),
            'valid_records': 0,
            'issues': []
        }
        
        valid_data = factor_data.copy()
        
        for column, rules in self.quality_rules.items():
            if column not in valid_data.columns:
                continue
            
            # 檢查並記錄異常值
            out_of_range = (
                (valid_data[column] < rules['min']) |
                (valid_data[column] > rules['max'])
            )
            issue_count = out_of_range.sum()
            
            if issue_count > 0:
                quality_report['issues'].append({
                    'column': column,
                    'issue': 'out_of_range',
                    'count': issue_count
                })
                
                # 異常值處理
                if rules['null_handling'] == 'use_median':
                    median_value = valid_data.loc[~out_of_range, column].median()
                    valid_data.loc[out_of_range, column] = median_value
        
        # 檢查空值
        null_counts = valid_data.isnull().sum()
        for column, count in null_counts.items():
            if count > 0:
                quality_report['issues'].append({
                    'column': column,
                    'issue': 'null_values',
                    'count': int(count)
                })
        
        quality_report['valid_records'] = len(valid_data)
        
        return valid_data, quality_report
```
