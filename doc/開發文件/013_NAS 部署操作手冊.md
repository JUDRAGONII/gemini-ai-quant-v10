# AI 投資分析儀 V10.0 NAS 部署操作手冊

**文件編號**：OPS-V10.0-001
**版本**：1.0.0
**建立日期**：2026-01-26
**功能說明**：本文件詳細說明在 QNAP TS-h973AX-32G NAS 設備上部署 V10.0 系統的標準操作流程。

---

## 1. 基礎環境要求

### 硬體配置 (TS-h973AX)
- **CPU**: AMD Ryzen™ V1500B (4-core/8-thread)
- **RAM**: 32GB DDR4 ECC (專案建議分配 8GB+ 給 Container Station)
- **Storage**: SSD 緩存加速需開啟，確保數據庫 I/O 效能

### 軟體環境
- **作業系統**: QTS / QuTS hero 5.1+
- **容器平台**: Container Station (Docker 20.10.x+)
- **儲存空間**: 建立專屬共有資料夾 `AI_Quant_V10`

---

## 2. 部署架構說明

系統採用 Docker Compose 進行多容器編排，主要服務包含：
- **PostgreSQL 15**: 存儲 538 萬筆+ 市場數據。
- **FastAPI Backend**: 核心邏輯、AI Agent、ETL 任務。
- **Next.js Frontend**: 使用者介面 (預設 Port: 3000)。
- **Supabase Stack**: 權限控制、即時 API。

---

## 3. 部署步驟

### Step 1: 檔案準備
1. 將專案根目錄上傳至 `/share/AI_Quant_V10`。
2. 檢查 `.env` 檔案中的 `DATABASE_URL` 與 `SUPABASE_URL`。

### Step 2: 啟動容器
開啟 SSH 或使用 QNAP 圖形介面進入 YAML 編輯器，執行：
```bash
docker-compose -f docker-compose.yml up -d
```

### Step 3: 端口映射 (Port Mapping)
| 服務 | 內部端口 | NAS 外部端口 | 說明 |
| :--- | :--- | :--- | :--- |
| Frontend | 3000 | 3000 | 使用者入口 |
| Backend | 8000 | 8000 | API 端點 |
| Supabase | 54321 | 54321 | 資料庫與整合介面 |

---

## 4. 聯通性驗證
1. **網頁訪問**: `http://<NAS_IP>:3000`
2. **API 檢查**: `http://<NAS_IP>:8000/api/v1/system/status`
3. **DB 連結**: 使用 DBeaver 連結 `<NAS_IP>:54321`

---

## 5. 常見問題排除 (FAQ)
- **記憶體溢位**: 若 `ai-worker` 崩潰，請檢查系統剩餘 RAM。
- **權限報錯**: 確保 `.docker` 目錄與資料夾權限為 775。
