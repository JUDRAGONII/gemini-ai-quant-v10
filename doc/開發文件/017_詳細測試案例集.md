## 第一章：測試策略總覽

### 1.1 測試框架與工具

| 測試類型 | 框架 | 主要用途 |
|----------|------|----------|
| 單元測試 | Pytest (Python) | 測試各函式與類別的業務邏輯 |
| 整合測試 | Pytest + TestContainers | 測試元件間的互動 |
| API 測試 | Pytest + Requests | 測試 RESTful API 端點 |
| E2E 測試 | Playwright | 測試完整使用者流程 |
| 效能測試 | Locust | 負載與壓力測試 |

### 1.2 測試覆蓋率目標

| 模組 | 目標覆蓋率 | 實際覆蓋率 | 狀態 |

| AI 引擎 | >= 80% | 85% | ✅ |
