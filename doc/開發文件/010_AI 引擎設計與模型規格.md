## 第一章：AI 引擎架構總覽

### 1.1 系統願景與設計目標

AI 投資分析儀 V10.0 的 AI 引擎採用「認知層」與「決策層」雙軌架構，旨在提供兼具深度理解能力與數學優化能力的智能投資分析系統。認知層利用大型語言模型（LLM）進行語意分析、多空辯論與報告生成，模擬專業投資人的思考邏輯；決策層則運用演化算法（EA）優化量化因子權重，尋找數學上的最佳解。兩個層級相互配合，確保投資建議既具備邏輯可解釋性，又經過嚴格的數學驗證。

本引擎的核心設計目標包括：提供可解釋的 AI 投資建議（每項建議皆附带信心分數與推理依據）、實現動態學習與適應市場變化（透過演化策略持續優化模型參數）、支援多維度分析（結合基本面、技術面、籌碼面與宏觀面因素）、確保分析結果的一致性與可重現性（每次分析皆可追溯至相同的輸入數據與模型版本）。

## 第二章：演化策略引擎

### 2.1 遺傳演算法原理

演化策略引擎採用遺傳演算法（Genetic Algorithm）模擬生物進化過程，自動尋找最佳的投資因子權重配置。相較於傳統的梯度下降法，遺傳演算法能夠在非凸、非連續的搜尋空間中找到接近最優解，且不易陷入局部最佳化。這對於投資策略優化特別重要，因為金融市場的回報曲面通常極為複雜，傳統最佳化方法難以確保找到全域最佳解。

演化流程的每個世代包含以下步驟：首先，評估當前族群中每個個體的適應度（Fitness），即該基因組在歷史回測中的風險調整後報酬；其次，根據適應度進行選擇，較優的個體有更高的機會傳遞基因至下一代；接著，執行交叉（Crossover）操作，隨機配對個體並交換部分基因；然後，執行突變（Mutation）操作，以一定機率改變基因值，增加族群多樣性；最後，產生新一代族群並重複上述過程，直到收斂或達到終止條件。

### 2.3 適應度函數設計

適應度函數是演化過程的核心，決定哪些基因組會被選中並傳遞至下一代。本系統採用的適應度函數設計如下：

$$ Fitness = \frac{R_p - R_f}{\sigma_p} \times (1 - Penalty) $$

其中各參數說明：
- $R_p$：策略年化報酬率
- $R_f$：無風險利率（預設 3%）
- $\sigma_p$：策略報酬的年化標準差
- $Penalty$：懲罰項，當最大回撤（MDD）超過閾值時觸發

**懲罰項計算**：

$$ Penalty = \begin{cases} 
0 & \text{if } MDD \leq 15\% \\
0.2 \times \frac{MDD - 15\%}{5\%} & \text{if } 15\% < MDD \leq 20\% \\
0.2 & \text{if } MDD > 20\%
\end{cases} $$

此設計確保演化出來的策略在追求高報酬的同時，也能有效控制風險。當最大回撤超過 20% 時，適應度會乘以 0.8 的懲罰係數，顯著降低該策略被選中的機會。

### 2.4 演化流程實現

```python
# evolution.py

from deap import base, creator, tools, algorithms
import numpy as np

class EvolutionEngine:
    def __init__(self, config):
        self.config = config
        self.pop_size = int(50 + config.get('pop_size_factor', 0) * 100)
        self.cx_prob = 0.7
        self.mut_prob = 0.05
        self.ngen = 100
        
        self._setup_ga()
    
    def _setup_ga(self):
        creator.create("FitnessMax", base.Fitness, weights=(1.0,))
        creator.create("Individual", list, fitness=creator.FitnessMax)
        
        self.toolbox = base.Toolbox()
        self.toolbox.register("attr_float", random.uniform, 0, 1)
        self.toolbox.register("individual", tools.initRepeat, 
                             creator.Individual, self.toolbox.attr_float, n=26)
        self.toolbox.register("population", tools.initRepeat, list, 
                             self.toolbox.individual)
        
        self.toolbox.register("evaluate", self._calculate_fitness)
        self.toolbox.register("mate", tools.cxBlend, alpha=0.5)
        self.toolbox.register("mutate", tools.mutGaussian, 
                             mu=0, sigma=0.1, indpb=0.1)
        self.toolbox.register("select", tools.selTournament, tournsize=3)
    
    def _calculate_fitness(self, individual):
        # 將基因組映射為實際參數
        params = self._decode_genome(individual)
        
        # 執行回測
        backtest_result = self._run_backtest(params)
        
        # 計算 Sharpe Ratio
        sharpe = backtest_result['sharpe_ratio']
        
        # 應用懲罰項
        penalty = 0
        if backtest_result['max_drawdown'] > 0.20:
            penalty = 0.2
        elif backtest_result['max_drawdown'] > 0.15:
            penalty = 0.2 * (backtest_result['max_drawdown'] - 0.15) / 0.05
        
        return sharpe * (1 - penalty),
    
    def _decode_genome(self, genome):
        return {
            'value_weight': genome[0],
            'growth_weight': genome[1],
            'quality_weight': genome[2],
            'momentum_weight': genome[3],
            'macro_weight': genome[4],
            'pe_threshold': 5 + genome[5] * 25,    # [5, 30]
            'pb_threshold': 1 + genome[6] * 4,     # [1, 5]
            'eps_growth_threshold': genome[7] * 50,  # [0, 50]
            'roe_threshold': 5 + genome[8] * 20,   # [5, 25]
            'momentum_threshold': genome[9],
            'long_hold_days': int(20 + genome[10] * 60),  # [20, 80]
            'short_hold_days': int(10 + genome[11] * 30), # [10, 40]
            'rebalance_days': int(5 + genome[12] * 25),   # [5, 30]
            'risk_tolerance': 0.5 + genome[13] * 0.5,
        }
    
    def evolve(self):
        pop = self.toolbox.population(n=self.pop_size)
        hof = tools.HallOfFame(5)
        
        stats = tools.Statistics(lambda ind: ind.fitness.values)
        stats.register("avg", np.mean)
        stats.register("min", np.min)
        stats.register("max", np.max)
        
        algorithms.eaSimple(pop, self.toolbox, 
                           cxpb=self.cx_prob, 
                           mutpb=self.mut_prob,
                           ngen=self.ngen, 
                           stats=stats, 
                           halloffame=hof,
                           verbose=True)
        
        return hof[0], pop
```

### 2.5 模型生命週期管理

演化出的最佳基因組會記錄於資料庫的 `evolution_genes` 表，並進行以下管理：

**版本控制**：每次演化產生的最佳基因組分配一個 `generation` 編號，並標記產出時間與來源數據窗口。

**樣本外測試（OOS）**：每個基因組在產出後，會在「看不見的數據」上進行驗證，確保模型不會過度擬合歷史數據。

**降級預警機制**：若最佳基因組的樣外測試績效連續兩週低於基準（Sharpe Ratio < 0.5 或 MDA > 15%），系統會自動觸發重新演化程序。

## 第三章：多代理人辯論引擎

### 3.1 正反合辯證法

多代理人辯論引擎模擬專業投資委員會的決策流程，透過「正方（Thesis）」與「反方（Antithesis）」的對立觀點，最終由裁判（Synthesis）綜合歸納出最終建議。此設計源自黑格爾的正反合辯證法，透過多元觀點的碰撞與整合，避免認知偏誤，產出更為客觀全面的投資分析。

辯論引擎的核心價值在於：模擬不同投資風格的觀點衝突（成長型 vs. 價值型）、識別分析過程中可能遺漏的風險因素、提供可追溯的推理過程供用戶審閱、透過信心分數量化分析的可靠程度。

### 3.4 辯論流程實現

```python
# agents/dialectic.py

from typing import Dict, Tuple
from langchain_gemini import ChatGemini
from langchain_groq import ChatGroq
import json

class DialecticEngine:
    def __init__(self, config):
        self.gemini = ChatGemini(model="gemini-1.5-flash", temperature=0.7)
        self.groq = ChatGroq(model="llama-3.1-70b-versatile", temperature=0.3)
        
        self.bull_prompt = self._load_prompt("bull_template.txt")
        self.bear_prompt = self._load_prompt("bear_template.txt")
        self.judge_prompt = self._load_prompt("judge_template.txt")
    
    def run_debate(self, stock_data: Dict) -> Dict:
        # Step 1: 準備上下文
        context = self._prepare_context(stock_data)
        
        # Step 2: 正方分析
        bull_result = self._run_agent(
            self.bull_prompt, 
            context,
            self.gemini  # 使用 Gemini 進行創意分析
        )
        
        # Step 3: 反方分析
        bear_result = self._run_agent(
            self.bear_prompt,
            context,
            self.gemini
        )
        
        # Step 4: 裁判合成
        synthesis_result = self._run_synthesis(
            bull_result,
            bear_result,
            context,
            self.groq  # 使用 Groq 進行結構化輸出
        )
        
        return {
            "bull_argument": bull_result,
            "bear_argument": bear_result,
            "synthesis": synthesis_result,
            "timestamp": datetime.now().isoformat()
        }
    
    def _prepare_context(self, stock_data: Dict) -> str:
        return f"""
        Stock: {stock_data['symbol']} - {stock_data['name']}
        Price: {stock_data['price']}
        
        Financials:
        - PE: {stock_data['financials']['pe']}
        - ROE: {stock_data['financials']['roe']}
        - Revenue Growth: {stock_data['financials']['revenue_growth']}%
        
        Technical:
        - RSI: {stock_data['technical']['rsi']}
        - MA20 vs Price: {stock_data['technical']['ma20_vs_price']}
        
        Quant Score: {stock_data['ai_score']['composite']}
        """
    
    def _run_agent(self, prompt_template: str, context: str, model) -> Dict:
        formatted_prompt = prompt_template.format(context=context)
        response = model.invoke(formatted_prompt)
        return self._parse_response(response)
    
    def _run_synthesis(self, bull: Dict, bear: Dict, context: str, model) -> Dict:
        judge_context = f"""
        Bull Argument: {json.dumps(bull)}
        Bear Argument: {json.dumps(bear)}
        Additional Info: {context}
        """
        response = self._run_agent(self.judge_prompt, judge_context, model)
        return response
```

```python
class PromptManager:
    def __init__(self, version="latest"):
        self.version = version
        self.manifest = self._load_manifest()
    
    def get_prompt(self, prompt_id: str) -> str:
        prompt_info = self._find_prompt(prompt_id)
        if prompt_info['version'] != "latest":
            prompt_info = self._find_prompt(prompt_id, version="latest")
        
        with open(prompt_info['file'], 'r', encoding='utf-8') as f:
            return f.read()
    
    def switch_version(self, new_version: str):
        self.version = new_version
        self.manifest = self._load_manifest()
        logger.info(f"Switched to prompt version {new_version}")
```

```python
# model_router.py

class ModelRouter:
    def __init__(self):
        self.models = {
            'gemini': {'client': GeminiClient(), 'quota': 1000, 'used': 0},
            'groq': {'client': GroqClient(), 'quota': 5000, 'used': 0}
        }
    
    def route(self, task_type: str, priority: str = "quality") -> str:
        if priority == "speed":
            return 'groq'
        
        if task_type in ["long_analysis", "report_generation"]:
            return 'gemini'
        
        # 根據剩餘配額動態調整
        for model_name, info in self.models.items():
            if info['used'] < info['quota'] * 0.8:
                return model_name
        
        return 'groq'  # fallback
    
    def record_usage(self, model_name: str, tokens: int):
        self.models[model_name]['used'] += tokens
```

## 第六章：Token 計費與成本監控

### 6.1 Token 追蹤

```python
# token_tracker.py

class TokenTracker:
    def __init__(self):
        self.daily_usage = defaultdict(int)
        self.monthly_usage = defaultdict(int)
        self.cost_per_1k_tokens = {
            'gemini': 0.00025,  # $0.25 per 1M tokens
            'groq': 0.00005    # $0.05 per 1M tokens
        }
    
    def track(self, model: str, prompt_tokens: int, completion_tokens: int):
        total_tokens = prompt_tokens + completion_tokens
        self.daily_usage[model] += total_tokens
        self.monthly_usage[model] += total_tokens
        
        cost = total_tokens / 1000 * self.cost_per_1k_tokens[model]
        self._record_cost(model, cost)
    
    def get_daily_cost(self) -> float:
        return sum(
            usage * self.cost_per_1k_tokens[model] 
            for model, usage in self.daily_usage.items()
        ) / 1000
    
    def get_monthly_cost(self) -> float:
        return sum(
            usage * self.cost_per_1k_tokens[model]
            for model, usage in self.monthly_usage.items()
        ) / 1000
```
