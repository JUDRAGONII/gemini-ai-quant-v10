# 智慧排名 雙語化與真實數據對接 (Phase 14.11)

此計畫目標為將「AI 智慧排名（Ranking）」模組從純前端假資料（mockRankingData）切換為全真實資料連線，並將所有硬編碼中文字串轉換為 `<Bilingual>` 雙語切換元件。

## User Review Required

> [!IMPORTANT]
> - 本計畫將移除 `generateRankingData` 假資料，且需要後端 `analysis_service.py` 進行資料庫查詢 Join (為了得到股票名稱與當日漲跌)。若 Supabase API Schema 無法直接 Join，可能需要在後端暫時給予預設名稱或額外查詢。
> - 計畫執行完畢後仍遵循「不 Push，只執行自動化歸檔」原則。

---

## Proposed Changes

### 1. 後端架構擴充 (Backend)
#### [MODIFY] `backend/services/analysis_service.py`
- 修改 `get_top_scores` 方法：在原本查詢 `stock_scores_18` 的邏輯中，以 `select("..., stocks!inner(name, change_percent)")` (或視實際 Table 關聯進行調整) 取回前端展示所需名稱與漲跌幅資訊。若無直接關聯則視情況透過附加查詢拼裝所需資訊。

#### [MODIFY] `backend/api/routers/analysis.py`
- 更新 Response Schema，確保輸出給前端的 `top-scores` API 包含 `name` (名稱) 與 `change_percent` (今日漲跌) 等必要欄位。

### 2. 前端介面與 API 對接 (Frontend)
#### [MODIFY] `frontend/app/ai/ranking/page.tsx`
- 移除 `@/data/mockRanking` 與靜態 State。
- 引入 SWR 並對接 `/api/v1/analysis/top-scores` 介面，以獲取真實的資料列表。
- 套用 `<Bilingual>` 到「智慧排名決策」、「重新評分」、「開發平均分」等頁面字串。
- 新增 Loading 與 Error 防呆保護介面。

#### [MODIFY] `frontend/components/RankingTable.tsx`
- 表頭部分全部替換為 `<Bilingual>`。例如：「綜合」 -> `Composite`。
- 新增處理 Loading 狀態的 Spinner 或骨架屏，並保持排序等功能的邏輯適配新欄位。

#### [MODIFY] `frontend/components/ScoreRadarChart.tsx`
- 雷達圖的 5 大評分維度名稱（價值、成長、動能等）確保與中英雙語兼容，必要時使用雙語或依據 `LocaleContext` 丟入正確字串。

### 3. 自動化測試 (TDD Automation)
#### [NEW] `frontend/__tests__/app/ai/ranking/page.test.tsx`
- 編寫最少 4 個測試用例 (TC-141101 ~ TC-141104)：
  1. 測試 `RankingTable` 的初始渲染與 API 加載中狀態。
  2. Mock 模擬 API 成功回傳後，確認雷達圖與排行列表上出現預期標的（且切換欄位可排序）。
  3. 錯誤或空值 (Empty State) 的呈現機制捕捉。
