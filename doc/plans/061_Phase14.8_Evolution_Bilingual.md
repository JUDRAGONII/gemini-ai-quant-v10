# Phase 14.8 演化分析 (Evolution) 雙語化與測試補齊計畫

演化分析模組 (`app/evolution`) 透過 `<EvolutionVisualizer>` 元件展示 AI 回測引擎的適應度與基因圖譜，為 V10.0 的核心 AI 特色之一。

## 專案現況深度剖析 (Current State Analysis)

### 1. 資料源分析 (Backend / BFF)
- **現狀極佳**：該模組已完全透過 `useEvolution.ts` 調用 `api/v1/evolution/history` 與 `api/v1/evolution/best` 兩個真實端點。完全**不含任何 Mock Data 依賴**。
- **後端狀態**：已對接 PostgreSQL 的 `evolution_history` 資料表，資料具備真實性。

### 2. 前端介面與雙語化狀況
- **`app/evolution/page.tsx`**: 標題與 `<StatusBadge>` 已雙語化，無須大改。
- **`EvolutionVisualizer.tsx`**: 基本架構已套用 `<Bilingual>`，但在「演化分析洞察 (EVOLUTIONARY INSIGHTS)」區塊下方，有一段描述：「當前最佳個體在第 X 代產出...」為**硬編碼純中文**。
- **`FitnessHeatmap.tsx`**: `<Area>` 的 `name` 屬性寫死為 `BEST FITNESS` 與 `AVG FITNESS`。這會出現在 Tooltip 與 Legend 中。
- **`GenomeMap.tsx`**: `GENE_LABELS` 已經妥善定義了中英文陣列，配合 RadarChart 渲染，整體狀態良好。

### 3. 單元測試狀況
- **嚴重缺失**：目前針對 `app/evolution` 及其附屬元件的 Jest 測試覆蓋率為 0 (測試檔不存在或未被執行)。

## 預期改動與實作計畫 (Implementation Plan)

遵循 KISS 遞進原則，由於核心狀態良好，修改將專注於補全與防禦。

### 階段一：精細化 UI 雙語補全 (Bilingual Enhancement)
#### [MODIFY] `components/AI/EvolutionVisualizer.tsx`
- 將 Footer Insight 區塊之動態文字，抽換為 `<Bilingual>`。
- 繁中：`當前最佳個體在第 ${generation} 代產出，適應度為 ${fitness}。基因圖譜顯示系統正朝向穩定獲利與低回撤的參數空間收斂。`
- 英文：`The current best individual was produced in generation ${generation} with a fitness of ${fitness}. The genome map shows the system is converging towards a parameter space of stable profitability and low drawdown.`

- 將 `<Area>` 之 `name` 透過 Tooltip/Legend 的 formatter 包裝或直接改為 `最佳適應度 (BEST FITNESS)`，以兼顧雙語閱讀與圖表限制。
