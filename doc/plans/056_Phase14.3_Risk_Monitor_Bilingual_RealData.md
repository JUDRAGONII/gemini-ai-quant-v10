## 📋 目標

1. **佈局修復**：修正 `/ai/risk` (法人級風險風控系統) 頁面雙重 Sidebar 導致的左側大片空白。
2. **微缺漏雙語化**：補齊 `/monitor/command-center` (AI 監控中心) 以及 `/ai/risk` 頁面內殘留的零星英文標籤。

## 🏗️ 佈局 Bug 根因與修復

*   **根因**：`app/ai/layout.tsx` 本身已渲染 `<Sidebar />` 與 `<MobileNav />` 並設有 `lg:ml-64`，而 `app/ai/risk/page.tsx` 內又自行引用並渲染了一次，導致重複加寬 (256px * 2 = 512px)。
*   **修復方式**：移除 `risk/page.tsx` 內自帶的 Layout components，並拔除外層的 `min-h-screen bg-[#050505] flex` 及 `lg:pl-64` 容器，直接擁抱父層 Layout。

## 📝 修改清單

### 1. `app/ai/risk/page.tsx` (佈局修復 + 雙語化 4 處)
- 佈局：移除 `Sidebar`、`MobileNav`、外層 `flex` 及 `lg:pl-64` 控制。
- 標題小標 `Institutional Grade` 替換為雙語 `法人級`。
- `ProInput` placeholder 加入中文提示 `搜尋標的 (如: 2330 / Search Ticker)`。
- 分析按鈕加入 `cursor-pointer`。
- 壓力測試 `Est. Recovery` 替換為雙語 `預估恢復` 與 `天`。

### 2. `app/monitor/command-center/page.tsx` (雙語化 1 處)
- 首次全域 Loading 畫面替換為 `<Bilingual zh="正在初始化 AI 監控中心..." en="INITIALIZING AI COMMAND CENTER..." />`。

### 3. `components/monitor/SystemHealthWidget.tsx` (雙語化 2 處)
- RAM `Total:` 替換為 `<Bilingual zh="總計" en="Total" />`。
- `API Quota` 狀態動態替換：`Healthy` → `正常 / Healthy`，`Warning` → `異常 / Warning`。

### 4. `components/monitor/RiskAlertWidget.tsx` (雙語化 2 處)
- `嚴重 (CRITICAL)` 標籤替換為 `<Bilingual />`。
- `+N more` 標籤替換為 `<Bilingual zh="其他 +N" en="+N more" />`。

### 5. `components/monitor/LiveAlertFeed.tsx` (雙語化 1 處)
- `實時 (REALTIME)` 標籤替換為 `<Bilingual />`。
