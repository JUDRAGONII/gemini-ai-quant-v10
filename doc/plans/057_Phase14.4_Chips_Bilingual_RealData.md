# Phase 14.4 — 籌碼分析頁面全繁體中文化與真實數據導入

## 🌟 核心目標
徹底消除 `app/chips` 模組四個子頁面（總覽、三大法人、融資融券）對假資料 (`MOCK_CHIPS_DATA`) 的依賴。實作單一的 Backend BFF API 以支援全頁面圖表所需的籌碼數據，並將所有硬編碼中文元件轉換為支援 `<Bilingual>` 機制的介面。

## 🏛️ 架構設計 (Architecture)
為了遵循 KISS 原則並降低前端發送 API Request 的次數與資料整型的負擔，我們在後端設計了 **單一聚合端點**。
* **端點**: `GET /api/v1/chips/{stock_code}?days=30`
* **後端實作 (`ChipsRepository`)**: 
  - 以 `daily_price` 的交易日為基準打底 (Left table)
  - `OUTER JOIN` `stock_institutional` (三大法人)
  - `OUTER JOIN` `stock_margin` (融券餘額)
  - 自動處理 Null 補零與前日結轉 (ffill)，回傳結構嚴謹的 JSON 給前端。

## 🧩 前端實作 (Frontend Hooks & Components)
* **Custom Hook (`useChipsData.ts`)**: SWR fetching 資料，並在 TS 中定義完美的 `ChipDailyData` Interface。
* **組件替換**:
  - `ChipsOverviewPage`: 替換各類 `StatCard` 的資料來源。
  - `InstitutionalPage`: 動態計算近 7 日累計買賣超並繪製在 `PieChart` 上；展示 30 日 Stacked Bar 趨勢。
  - `MarginPage`: 動態讀取融資融券餘額、增減及券資比，繪製於 `AreaChart` 中。
* **UI 雙語化**:
  - 套用 `<Bilingual>` 於標題、統計卡片與各統計圖例 (`LegendItem` & `Recharts` 鍵值對應)。
