## 🏛️ 1. 系統架構評估 (Architect Review)

### 1.1 計算下沉 (Computation Offloading)
- **正面評價**：明確採用 `PostgreSQL Window Functions` 計算 MA 指標，此舉將大幅降低前端 JS 運算負擔，符合 V10.0 的高效能標準。
- **架構建議**：
  > [!IMPORTANT]
  > 針對 MACD 等較複雜指標，SQL Window Functions 語法會變得異常冗長且難以維護。建議對這類指標採用 **「寫入時計算 (Pre-calc on Write)」** 或 **「快取物化視圖 (Materialized View)」**。

### 1.2 資料表擴充
- **審核結果**：新增的 `stock_institutional` (法人) 與 `stock_margin` (融資券) Table Schema 設計符合 SDD 規範。
